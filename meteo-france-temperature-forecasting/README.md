# Meteo-France Temperature Forecasting 

This project presents a structured, end-to-end workflow developed in Python for 
**forecasting hourly surface air temperatures (T)** using open Meteo-France weather station data. 
The entire pipeline focuses exclusively on the temperature variable, treating each weather 
station as an independent time series.

## Dataset Source

- **Departments Used:** 61 and 69

The raw data files are downloaded from the official portal and placed in the project root directory.

## Project Structure and Execution Order

The project consists of **six notebooks that must be executed sequentially**.  
Each notebook depends on data, features, or models generated by the previous step.

### 1. Data Ingestion and Cleaning
**Notebook:** `01_data_ingestion_and_cleaning.ipynb`

- Load raw Meteo-France CSV files
- Normalize column names and parse timestamps
- Remove duplicates and invalid records
- Reindex each station to a complete hourly timeline
- Interpolate missing values (linear, then forward/backward fill)
- Perform seasonal decomposition (24-hour cycle)
- Standardize variables and save cleaned station-level datasets

---

### 2. Exploratory Analysis and Feature Engineering
**Notebook:** `02_eda_and_feature_engineering.ipynb`

- Identify stations and temporal coverage
- Perform exploratory data analysis (EDA)
- Visualize trends, distributions, and missingness
- Generate calendar-based features (hour, day, month)
- Create lagged temperature features
- Apply chronological train/test splits

---

### 3. Global Regression Models
**Notebook:** `03_global_regressors_evaluation.ipynb`

- Aggregate data across all stations
- Train global models:
  - Linear Regression
  - Random Forest Regressor
- Evaluate global performance using RMSE and R²
- Analyze model generalization across stations
- Inspect feature importance and time-dependent errors

---

### 4. Station-Level Modeling
**Notebook:** `04_station_level_modeling.ipynb`

- Train independent models for each station
- Apply scaling and time-aware validation
- Compare station-level models against global baselines
- Store per-station metrics and trained models
- Analyze inter-station performance variability

---

### 5. Station Clustering Analysis
**Notebook:** `05_station_clustering_pca_kmeans.ipynb`

- Build statistical profiles for each station
- Standardize station feature vectors
- Apply PCA for dimensionality reduction
- Perform clustering:
  - K-means
- Determine optimal cluster count (elbow & silhouette)
- Visualize clusters and centroids
- Export cluster labels for downstream use

---

### 6. Sequence Modeling with LSTM
**Notebook:** `06_lstm_sequence_forecasting.ipynb`

- Construct sliding-window time series sequences
- Balance samples across stations and clusters
- Train LSTM / sequence-to-sequence models
- Perform multi-step temperature forecasting
- Compare predicted and observed trajectories
- Analyze performance across forecast horizons

## How to Run

1. Install **Python 3.10+**
2. Install required dependencies:
   - pandas  
   - numpy  
   - scikit-learn  
   - matplotlib  
   - seaborn  
   - statsmodels  
   - joblib  
   - tensorflow / keras  

3. Download the Meteo-France data files and place them in the project root
4. Execute the notebooks **in the order listed above**

Each notebook documents its parameters, intermediate outputs, and results.
